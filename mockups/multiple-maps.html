Several maps on one device

Varda keeps every imported map instead of only one. You switch maps from a new button on the map, which keeps the place and zoom, or from ⋯ → Maps, where you also add and remove them. Elevation is stored separately as named sets. Any map can use any set for hillshading, so GPSmap.is and Freizeitkarte can share the same Iceland 1″ files.

Underneath

Storage. Each map in its own folder (maps/<id>/map.img, meta, places cache); each elevation set in its own folder (elevation/<id>/*.hgt + its overview). A small list file names the maps, their hillshading set and the current map, written last as today's pointer is. The dev version keeps its own folders as before.

Upgrade. On first start the stored map moves to the new layout as the only map. Its .hgt files become a set named from what they are ("Iceland 1″ HD" if 1″). Nothing is downloaded or re-imported.

Switching rebuilds the map's tile workers and style without a page reload. Search, routing and the places cache follow the current map. Saved places, tracks and photos stay shared. Sync doesn't carry maps; it can carry each map's chosen name and hillshading later if wanted.
